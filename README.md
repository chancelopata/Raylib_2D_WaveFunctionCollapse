# The Project
This script creates a 2D grid world using the wave function collapse algorithm. The world is random every time and is drawn to the screen using Raylib.
The grid world is broken up into Tiles that each store their own coordinate on the grid as well as their current state.

## Creating your own custom world!
Your own world can be created by tweaking the following constants located near the top of the program.

- WORLD_HEIGHT: Number of rows in the world.
- WORLD_WIDTH: Number of collumns in the world.
- TILE_SIZE: Size of the Tiles in pixels
- COLORS: a list of colors that acts as the ruleset for the wave function collapse algorithm. A Color can only touch colors that are adjacent to its index.
